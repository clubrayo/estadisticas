# CLUB RAYO — Sistema de Gestión y Estadísticas de Juego

Aplicación web mobile-first para gestionar campeonatos, partidos, listas de juego y
estadísticas de aerocombate del CLUB RAYO.

- `app/` — aplicación web (Vite + React + TypeScript + Tailwind). Ver `app/README.md`.
- `supabase/migrations/` — migraciones de base de datos, numeradas y en orden. Una migración ya ejecutada nunca se modifica.
- `supabase/verificacion/` — suites de prueba (ver `supabase/verificacion/README.md`).
- `supabase/operaciones/` — scripts de mantenimiento puntuales.

Publicación: Netlify, con la configuración de `netlify.toml`.
